# OptiSys v28 design

The UI deliberately follows professional photographic workstation patterns: a dark neutral workspace, module-like Library/Loupe workflow, persistent catalog, large image area, metadata panels, grid and filmstrip navigation. This mirrors the structural concepts Adobe documents for Lightroom Classic: Library for organizing/selecting, a central image display, side panels, toolbar and filmstrip. OptiSys does not copy Adobe code or assets.

Current release: v27.2 visual workstation foundation.
