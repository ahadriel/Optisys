# OptiSys v27.1 — WORKSTATION

Full local-first event photography workstation.

Workflow:
INGEST -> VERIFY -> CATALOG -> REVIEW -> CULL -> RATE -> SELECT -> EXPORT -> REPORT

Features:
- Event management
- Recursive camera/card import
- Optional verified copying into Originals
- SHA-256 checksums
- Duplicate detection
- File verification
- RAW/JPEG/PNG/TIFF/WEBP cataloging
- EXIF metadata
- Cached thumbnails
- Search and filters
- 1-5 rating, reject, clear
- Keyboard culling: arrows, 1-5, X, 0, Space
- Contact sheets
- Verified Selects export
- CSV reporting
- Photoshop and Lightroom launch paths
- Local SQLite catalog
- C: destination protection
- No client-photo upload

Run with run_optisys.bat.
